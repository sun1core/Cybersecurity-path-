#### Intrusion Detection System ( IDS )

###### Security monitoring with detection tools 
1. TELEMENTRY 
---> collection and transmission of data for analysis.

2. Intrusion Detection System ( IDS )
---> an application that monitors activity and alerts on possible intrusions

3. Endpoint 
---> any device connected on a network 

4. Host-Based Intrusion Detection System 
---> application that monitors the activity of the host on which it's installed 

5. Network-Based Intrusion Detection System 
---> application that collects and monitors network traffic and network data 

6. Signature Analysis
---> Detection method used to find events of interest 


#### Components of a Detection System
##### Components of NIDS rule ( signature Analysis )
