
## Module -1 Introduction to Asset Security 

###### Risk 
- anything that can important the confidentiality, integrity and availability of an asset.

##### Security Risk Planning
1. Assets
---> An item perceived as having value to an organization

2. Threat 
---> Any circumstances or event that can negatively impact

3. Vulnerability
---> Weakness that can be exploited by a threat

##### Security starts with asset classification 
1. Asset Management
---> process of taking assets and the risks that affect them.

2. Asset Inventory 
---> Catalog of assets that need to be protected

3. Asset Classification
---> practice of labelling assets based on sensitivity an importance to an organization

##### Levels of asset classification 
- public
- internal-only
- confidential
- restricted

##### Organization protect variety of different assets;
- Digital assets, such as customer data
- Information systems that process data
- Physical assets which can include facilities
- Intangible assets such as brand reputation


#### Digital and Physical assets
###### Data 
---> Information that is translated, processed or stored by a computer

##### States of data 
1. Data in use 
---> data being accessed by one or more users

2. Data in Transit
---> data travelling from one point to another.

3. Data at Rest 
---> Data not currently being accessed


###### Information Security ( InfoSec )
---> Practice of keeping data in all states away from unauthorized users

##### The emergence of Cloud Security 
###### Three main categories cloud-based services;
- Software as a Service ( SaaS )
- Platform as a Service ( PaaS )
- Infrastructure as a Service ( IaaS )

##### Cloud Security Challenges;
- misconfiguration
- cloud-native breaches
- monitoring access might be difficult
- meeting regulatory standards


#### Risk & Asset Security
##### Types of risk categories;
- damage 
- disclosure
- loss of information 

##### Elements of a security plan;
1. Policies 
---> set of rules that reduces risk and protect information

2. Standards 
---> References that inform how to set policies 

3. Procedures
---> Step-by-step instructions to perform a specific security task.

##### The NIST Cybersecurity Framework ( CSF )
###### Compliance
---> process of adhering to internal standards and external regulations

###### Regulations 
- rules set by a government or other authority to control the way something is done

###### NIST Cyber Security Framework ( CSF )
- Voluntary framework that consists of standards, guidelines, and best of practice to manage cyber security risk

##### NIST CSF Component;
- core 
- Tiers
- Profiles

##### Five functions of the NIST CSF core 
- Identity 
- protect 
- detect 
- respond
- recover
- Govern
