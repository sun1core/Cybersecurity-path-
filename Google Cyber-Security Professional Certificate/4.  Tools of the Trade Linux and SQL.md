##### The User Interface 
###### User Interface
- A program that allows the user to control the functions of the operating system.

###### Graphical User Interface ( GUI )
- user interface that uses icons on the screen to manage different tasks on the computer.

###### Basics GUI Components;
- Start Menu
- Taskbar
- Desktop with icons and shortcuts

###### Command Line Interface ( CLI )
- text-based user interface that uses commands to interact with the computer.
