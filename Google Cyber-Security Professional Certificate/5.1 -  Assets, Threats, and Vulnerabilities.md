### Phishing 
- the use of digital communications to trick people into revealing sensitive data or deploying malicious software
###### Phishing Kit
- collection of software tools needed to launch a phishing campaign 
     *Phishing kit tools
     - malicious attachments
     - fake data-collection forms

###### Smishing 
- use of text messages to obtain sensitive information or to impersonate a known source 

###### Vishing

### Malware 
###### Malicious Software 
- designed to harm devices or networks
##### Types of malware
1. virus
---> malicious code written to interface with computer operations and cause damage to data and software 

2. Worm
---> Malware that can duplicate spread itself across systems on its own 

3. Trojan ( or Trojan Horse )
---> malware that looks like a legitimate file or program 

4. Ransomware 
---> type of malicious attack where attackers encrypt an organizations data and demand payment to restore access

5. Spyware
---> malware that's used to gather and sell information without consent

### The Rise of Cryptography 
###### Cryptography 
- a form of malware that installs software to illegally mine cryptocurrencies

##### Signs of crypto jacking 
- slowdown 
- increased CPU usage 
- sudden system crashes
- fast draining batteries
- unusually high electronic costs 


### Web Based Exploits 
- malicious code or behavior that's used to take advantage of coding flaws in a web application 

###### Injection Attack 
- malicious code inserted into a vulnerable application

#### Cross-Site Scripting ( XSS )
- injection attack that inserts code into a injection vulnerable website or web application
##### Types of XSS Attacks
1. Reflected XSS Attack
---> instance when malicious script is sent to a server and activated during the server's response

2. Stored XSS Attack
---> instance when malicious script is injected directly on the server

3. DOM- Based  XSS Attack ( Document Object Model )
---> instance when malicious script exists in the web page a browser loads
