

## Module - 3 Vulnerabilities in systems
#### Vulnerability Management 
###### Vulnerability 
- weakness that can be exploited by a threat 

###### Exploit
- way of taking advantage of a vulnerability 

###### Vulnerability Management
- process of finding and patching vulnerabilities
##### Steps of vulnerability management 
- identify vulnerabilities 
- consider potential exploits 
- prepare defenses against threat 
- evaluate those threats

###### Zero-day exploit
- exploit that was previously unknown 

#### Vulnerabilities of CI/CD
*What is CI/CD? Why does it matter?*
- automates the entire software release process, from code creation to deployment. This automation is what enables modern development teams to agile and respond quickly to user needs. 

##### CI ---> Continuous Integration ( Building a solid foundation )
##### CD ---> Continuous Delivery ( Ready to release )

      Continuous Integration           Continuous Delivery                 Continuous Deployment
      Build---> test ---> merge ---> Automatically release to repository ---> automatically   deploy to production 


##### Why a secure CI/CD pipeline is non-negotiable?
- secure automation 
- improve code quality via security checks
- faster time to  market for security updates
- enhanced collaboration and feedback with safety focus 
- reduced risk 

###### Defense in depth strategy 
- a  layered approach to vulnerability management that reduces risk 
##### layers;
- perimeter layer 
- network layer
- endpoint layer 
- application layer
- data layer 

#### Common Vulnerabilities and Exposure
###### Exposure 
- mistake that can be exploited by a threat

###### Common Vulnerabilities and exposure list ( CVE List )
- an openly accessible dictionary of known vulnerabilities and exposures

###### MITRE 
- collection of non-profit research and development centers

###### CVE Numbering Authority ( CNA )
- organization that volunteers to analyze and distribute information on eligible CVEs.

##### CVE list Criteria;
1. Independent to other issues 
2. recognized as a potential security risk 
3. submitting with supporting evidence 
4. only affect one codebase 

###### Common Vulnerability scoring system ( CVSs )
- Measurement system that scores the severity of a vulnerability

### Cyber attack Mindset

###### Attack Surface
- all the exponential vulnerabilities that a threat actor could exploit 

###### Security Hardening
- process of strengthening a system to reduce its vulnerabilities and attack surface 

##### Types of threat actors 
###### Threat actor 
- any person or group who presents a security risk 

##### divided into 5 categories
1. competitors
2. state actors
3. criminal syndicates 
4. insider threat 
5. shadow IT

##### Types of hackers 
1. unauthorized hackers
2. authorized or ethical hackers
3. semi-authorized hackers

##### Threat actors gain through 
- direct access
- removable media
- social media platforms
- email
- wireless networks
- cloud services 
- supply chains

###### Pathway through defenses 
- pathway attackers used to penetrate security defense 

##### Practicing an attacker mindset 
1. identify a target 
2. determine how the target can be accessed
3. evaluate attack vectors that can be exploited 
4. find the tools and methods of attack 

##### Defending attack vectors
1. educating users
2. applying the principle of least privilege
3. using the right security controls and tools
4. building a diverse security team
