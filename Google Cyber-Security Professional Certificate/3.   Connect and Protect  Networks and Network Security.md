
## Module -1 Network Architecture

###### Network 
- Group of connected devices

###### Local Area Network ( LAN )
- Network that spans a small area like office, building, a school or home.

###### Wide Area Network ( WAN )
- Network that spans a large geographic area like a city, state or country.


##### Network Tools

1. Hub
--> Network service that broadcasts information to every device on the network

2. Switch
--> Devices that makes connections between specifies on a network by sending and receiving data between them.

3. Router
--> Network device that connects multiple network together.

4. Modem
--> Devices that connects your router to the internet brings access to the LAN.

5. Virtualization
--> Pieces of software that perform network operations.

##### TCP/IP Model 
###### ( TCP ) Transmission Control Protocol
--> Internet communication protocol that allows two devices to form a connection and a stream data

###### ( IP ) Internet Protocol
--> Set of standards used for routing and addressing data packets as they travel between devices on a network

###### Port 
--> Software based location that organize the sending and receiving of data between devices on a network

###### Port Numbers
- port 25 - Email
- Port 443 - Secure Internet Communication
- Port 20 - Large File Transfers

##### The layers of TCP/IP Model

###### TCP/IP Model
--> framework used to visualize how data is organized and transmitted across the network

#### Layers of TCP/IP Model 
1. Network Access Layer - Ethernet, wireless LAN
2. Network Layer - IPV4, IPV6
3. Transport Layer - TCP, UDP
4. Application Layer - HTTPS, TLS, DNS

## Module - 2 Network Operations

##### Network Protocols
- set of rules used by two or more devices on a network to describe the order of delivery and the structure of the data

###### Transmission of Protocol ( TCP )
- internet communications protocol that allows two devices to form a connection and stream data

###### Address Resolution Protocol ( ARP )
- network protocol used to determine MAC address of the next router or device on the path.

###### Hyper Text Transfer Protocol ( HTTPs )
- Network protocol that provides a secure method of communication between clients and website server.

###### Domain Name System
- Network protocol that translate internet domain name into IP address.


##### Security protocols
- HTTPs
- SSL/TLS

##### Protocol and Port 
1. DHCP ---> UDP Port 67 ( servers ) & UDP port 68 ( Clients )
2. ARP ---> None
3. Telnet ---> TCP Port 23 
4. SSH ---> TCP Port 22
5. POP3 ---> TCP/UDP port 110 ( unencrypted ) & TCP/UDP port 995 ( encrypted SSL/TLS )
6. IMAP ---> TCP port 143 ( unencrypted ) & TCP port 993 ( encrypted SSL/TLS )
7. SMTP ---> TCP/UDP  port 25 ( unencrypted )
8. SMTPS ---> TCP/UDP port 587 ( encrypted, TLS ) 


#### Wireless Protocols 
*IEEE --> Institute of Electrical and Electronics Engineer

###### IEEE 802.11 ( WIFI )
- set of standards that define communication for wireless LANs.

###### WIFI Protect Access ( WPA )
- wireless security protocol for devices to connect to the internet.

#### System Identification 
Firewalls and  Network Security Measures

###### Firewall 
- a network security device that monitors traffic to and from your network

###### Port Filtering 
- A firewall function that blocks or allows certain port numbers to limited unwanted communication

###### Cloud-Based Firewall
- software firewalls that are hosted by a cloud service provider 

###### Stateful 
- A class of firewall that keeps track of information passing through it and proactively filters out threats.

###### Stateless
- class of firewall that operates based on predefined rules and doesn't keep track of information from data packets

##### Benefits of Next Generation Firewalls ( NGFWs )
- deep packet inspection
- Intrusion Protection
- Threat Intelligence

###### Virtual Private Networks ( VPNs )
- network security that changes your public IP address and hides your virtual location so that you can keep your data private when you are using public network like the internet.

###### Encapsulation
- process performed by a VPN service that protects your data by wrapping sensitive data in other data packets

#### Security Zones
- segment of network that protects the internal network from the internet

###### Network Segmentation
- security techniques that divides the network into segments

###### Uncontrolled Zones 
- any network outside of the organization's control

###### Controlled Zones
- subnet that protects the internal network from the uncontrolled zone

##### Areas in the controlled Zone
- Demilitarized Zone ( DMz )
- internal network
- restricted zone


#### Subnetting & CIDR 
###### Subnetting 
process of taking one large network dividing into several smaller, organized groups.

*combination of IP address and network mask 

###### Classless Inter-Domain Routing ( CIDR )
- method of assigning subnet masks to IP address to create a subnet

#### Proxy Server ( NAT )
- server that fulfills the requests of a client by a forwarding them on the other servers

###### Forward Proxy server
- regulates and restricts a person's access to the internet

###### Reverse Proxy Server
- Regulates and restricts the internet's access to an internal server.
